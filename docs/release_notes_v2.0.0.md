## 软件简介

**浮黎 (Memoria)** — 一站式缓存混流工具

将 B站等平台缓存中分离的音视频流一键混流为标准视频文件，留下互联网的记忆。

---

## 主要功能

### 核心混流
- 自动解析缓存文件（entry.json / index.json），提取视频元数据（标题、UP主、BV号、分P等）
- 将独立视频流与音频流混流合并为完整视频文件
- 支持 **MP4 / MKV / MOV**（流复制，无需重编码，秒级完成）
- 支持 **WEBM**（VP9 + Opus 转码导出）

### 多种导入方式
| 方式 | 说明 |
|------|------|
| 独立导入 | 直接选择本地缓存文件夹 |
| ADB 无线导入 | WiFi 连接 Android 设备，远程浏览并拉取 B站缓存目录 |
| 外部设备导入 | USB 数据线连接设备传输 |

### 批量处理
- 任务队列支持多视频排队混流，自动依次处理
- 文件名自动净化（去除 Windows 非法字符）

### 视频预览
- 内置播放器，混流前预览确认视频内容

### 工具自检
- 自动检测系统 FFmpeg / ADB 环境，缺失时回退至内置工具

---

## 使用方法

1. 下载安装包（安装程序 `.exe` 或便携版 `.zip`）
2. 运行 Memoria
3. 选择导入方式，定位 B站缓存文件夹（通常位于 `Android/data/tv.danmaku.bili/download`）
4. 勾选要混流的视频
5. 设置输出格式和保存路径
6. 开始混流，等待完成
