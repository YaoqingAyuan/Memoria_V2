# Memoria V2

> 一款专注于**视频缓存管理与混流导出**的桌面端工具，支持从本地或移动设备读取 B 站等平台的视频缓存文件，解析元数据、批量混流导出为通用格式。内置双屏预览系统，支持本地缓存播放与云端在线对比。**V2.1.1 正式版已发布**：支持 Bilibili 平台，暂不支持其他平台

## 概述

Memoria 是一款面向视频缓存文件管理的桌面应用程序，旨在帮助用户：

* **读取视频缓存文件** — 从本地文件系统或移动设备读取 B 站等平台的离线缓存

* **可视化元数据** — 解析并以表格形式展示标题、UP主、BV号、分P、分辨率、弹幕数等信息

* **混流导出** — 将分离的音视频流（.m4s）合并为 MP4 / MKV / MOV / WEBM 等通用格式

* **批量处理** — 支持多文件同时导入与批量混流导出

* **双屏预览对比** — 左侧本地缓存播放，右侧云端在线播放，方便对比画质差异

* **在线搜索与播放** — 通过 B 站 API 搜索视频，登录后可高清晰度云端播放

## 核心功能

### 数据导入

| 导入方式         | 说明                                          |
| ------------ | ------------------------------------------- |
| 本地文件导入       | 从本地文件系统选择缓存文件夹，自动解析 entry.json / index.json |
| 外部设备导入（USB）  | 通过 USB 数据线连接安卓设备，使用 ADB 拉取缓存文件              |
| 外部设备导入（WiFi） | 通过无线局域网连接安卓设备，无线调试 + ADB 拉取                 |
| 独立音视频导入      | 手动选择独立的视频文件和音频文件进行混流                        |

### 数据展示

* **元数据表格** — 8 个强制列（序号、状态、标题、分P号、分P标题、视频路径、音频路径、进度）+ 10 个可选列（离线ID、BV号、视频类型、UP主、UP主UID、创建时间、时长、文件大小、弹幕数、分辨率）

* **列头自定义** — 在设置 → 列头设置中自由勾选可选列的显隐

* **右键菜单** — 支持独立导入、编辑标题、删除行、清空行等快捷操作

### 混流导出

* **批量导出** — 选择多行一次性提交混流任务，顺序执行

* **实时进度** — 表格内显示每行的导出进度百分比

* **FFmpeg 自检** — 启动时自动检测 FFmpeg 环境（优先系统 PATH，回退到随包 FFmpeg）

### 视频预览系统

* **双屏对比播放** — 左侧本地预览播放缓存文件，右侧在线预览播放云端流，方便对比画质

* **本地预览** — 将缓存的 .m4s 音视频流混流为临时文件后通过 QMediaPlayer 播放

* **在线预览** — 通过 B 站 API 获取播放地址，经本地 HTTP 代理服务器 + FFmpeg 实时混流播放 DASH 流

* **多P支持** — 自动识别视频分P列表，提供分P切换下拉框，按 CID 精准匹配当前缓存对应的分P

* **临时文件管理** — 预览产生的临时文件存储于 AppData，程序启动时自动清理；异常崩溃后残留文件也会在下次启动时自动清除

### 在线搜索与播放

* **搜索功能** — 支持按标题关键词或 BV/AV 号搜索 B 站视频

* **卡片式结果展示** — 搜索结果以卡片形式展示，包含封面缩略图、标题、UP主、播放量等信息

* **下架检测** — 自动检测视频是否已下架，并在界面上显示状态

* **云端播放** — 搜索后可直接点击播放，系统自动获取播放地址并通过代理服务器流式播放

### 登录系统

* **扫码登录** — 本地生成 B 站登录二维码，手机扫码即可登录

* **登录状态保持** — 支持记住登录状态，下次启动自动登录

* **状态实时显示** — UI 实时显示当前登录状态（未登录 / 已登录 + 用户名）

* **右键退出登录** — 登录按钮支持右键菜单退出登录

> 登录后可获取更高清晰度的播放地址；未登录状态下仅支持基础清晰度（480P）的在线播放。

## 主要特性

* **零配置要求** — 内置 FFmpeg 与 ADB 环境，下载即用

* **多连接方式** — USB 有线 + WiFi 无线，适配不同使用场景

* **智能缓存管理** — 拉取的缓存文件自动存储于 AppData，支持过期清理与手动清理

* **跨平台音视频处理** — 基于 FFmpeg，支持流复制（秒级导出）与转码两种模式

* **Windows 文件名安全** — 自动清洗非法字符，避免导出失败

* **双屏预览对比** — 本地缓存与云端在线同屏对比，直观感受画质差异

* **本地代理流式播放** — 内置 HTTP 代理，支持在线播放

## 使用说明

### 环境要求

* Windows 10/11（64 位）

* 安卓设备（USB/WiFi 导入需要 Android 11+ 无线调试支持）

### 下载与安装

1. 从 [Release 页面](https://github.com/YaoqingAyuan/Memoria_V2/releases) 下载最新版本的安装包或压缩包
2. 运行安装程序或解压到任意目录
3. 运行 `Memoria_N_V2.exe`

> 软件已内置 FFmpeg（`FFmpeg_tools/bin/`）和 ADB（`ADB_tools/bin/`），无需额外配置环境。

### 基本使用流程

```
导入缓存数据 → 表格预览元数据 → 选择导出行 → 设置输出格式 → 点击"混流导出"
```

1. 点击主界面的 **"本地文件导入"** 或 **"外部设备导入"** 按钮
2. 选择要导入的缓存文件夹（本地选择目录 / 外部设备浏览设备文件）
3. 数据进入表格后，勾选或选中要导出的行
4. 点击 **"混流导出"** 按钮，在输出设置对话框中选择格式和输出目录
5. 等待混流完成，进度实时显示在表格中

### 预览使用流程

1. 在表格中选中一行，点击 **"预览"** 按钮打开预览窗口
2. 左侧自动加载本地缓存视频进行播放
3. 如需在线对比：

   * 点击 **"登录"** 按钮扫码登录 B 站（可选，提升清晰度）

   * 搜索结果自动显示在侧边栏，点击 **"播放"** 按钮即可在线播放

   * 多P视频可通过下拉框切换分P

## 外部设备导入使用指南

### 一、USB 有线连接

**适用场景**：设备在手边，有 USB 数据线

#### 步骤

1. **手机端**：开启开发者选项 → 开启 **USB 调试**（详见 [下方各品牌指南](#安卓设备开启开发者模式)）
2. 用 **USB 数据线** 连接手机和电脑
3. 手机弹出 **"允许 USB 调试吗？"** → 勾选"始终允许" → 点 **确定**
4. 打开 Memoria，点击 **"外部设备导入"**
5. 点击 **"刷新设备"** — 设备列表应显示已连接的手机
6. 点击设备名称 → 自动浏览 B 站缓存目录
7. 选中目标文件夹 → 点击 **"解析选中文件"** → 预览解析结果
8. 勾选要导入的项 → 点击 **"确认导入"** → 数据进入主表格

> **提示**：USB 连接无需配对/连接步骤，是最简单的测试方式。请确保使用支持数据传输的 USB 线（非纯充电线）。

### 二、WiFi 无线连接

**适用场景**：设备不在手边，或不想插线

#### 前置条件

* 手机和电脑在 **同一 WiFi 网络** 下

* 手机系统为 **Android 11 及以上**（支持无线调试功能）

#### 步骤

**第 1 步：配对（仅首次需要）**

1. 手机开发者选项 → 开启 **无线调试**
2. 点击 **"使用配对码配对设备"**
3. 手机屏幕显示：

   * **WiFi 配对码**：6 位数字（如 `348521`）

   * **配对地址**：如 `192.168.1.8:42171`
4. 在 Memoria 的外部设备导入窗口中，点击 **"配对"**
5. 第一个对话框输入 **配对地址**（`192.168.1.8:42171`）
6. 第二个对话框输入 **6 位配对码**
7. 状态栏显示 **"已配对，请连接"** → 配对成功

> **注意**：配对端口与连接端口**不同**！配对页面显示的端口仅用于配对。

**第 2 步：连接**

1. 退出配对码页面，回到 **无线调试主页面**
2. 页面底部显示 **连接地址**（如 `192.168.1.8:45123`）— 注意端口与配对不同
3. 在 Memoria 的连接输入框中输入此 **连接地址**
4. 点击 **"连接"** 按钮 → 状态栏显示 **"已连接"**

**第 3 步：使用**

1. 点击 **"刷新设备"** → 设备列表显示已连接的设备
2. 点击设备名称 → 自动浏览 B 站缓存目录
3. 后续操作与 USB 连接相同

#### 常见问题

| 问题            | 解决方法                              |
| ------------- | --------------------------------- |
| 刷新设备列表为空      | 检查 USB 调试是否开启、USB 线是否支持数据传输       |
| 配对失败          | 确认输入的是**配对页面**的 IP:端口，不是无线调试主页的端口 |
| 连接被拒绝 (10061) | 确认已先完成配对，且使用的是**无线调试主页**的 IP:端口   |
| 设备显示"未授权"     | 检查手机上是否有未响应的 USB 调试授权对话框          |
| 文件列表为空        | B 站缓存路径可能不同，用"上级目录"逐级查找           |

## 缓存管理

### 存储位置

| 类型       | 路径                                                                  | 说明                           |
| -------- | ------------------------------------------------------------------- | ---------------------------- |
| ADB 拉取缓存 | `C:\Users\<用户名>\AppData\Local\Memoria_N_V2\Memoria_N_V2\adb_cache\` | 使用 AppLocalData 目录，不会被系统自动清理 |
| 预览临时文件   | `C:\Users\<用户名>\AppData\Local\Memoria_N_V2\preview_cache\`          | 本地预览和在线预览的临时文件，启动时自动清理       |

### 自动清理策略

| 时机       | 动作              | 说明           |
| -------- | --------------- | ------------ |
| 混流导出成功后  | 删除该项目的缓存        | 文件已产出，缓存不再需要 |
| 从表格删除数据行 | 删除该行对应的缓存       | 用户不再需要       |
| 应用启动时    | 清理过期缓存 + 预览临时文件 | 崩溃恢复 + 过期清理  |
| 应用关闭时    | 按设置清理           | 可选：全量清理或过期清理 |

### 手动管理

在 **设置 → 缓存管理** 选项卡中：

* **关闭时清理全部缓存**：勾选后每次关闭应用时全量清理（最省空间）

* **缓存保留 N 天后自动清理**：不勾选上述选项时生效，默认 7 天，可设 1-30 天

* **手动清理**：显示当前缓存大小，一键清理全部缓存

> **本地文件导入**的数据不受缓存管理影响 — 仅 ADB 拉取的文件受生命周期管理。

## 导出格式支持

| 格式   | 扩展名   | 处理方式 | 说明                            |
| ---- | ----- | ---- | ----------------------------- |
| MP4  | .mp4  | 流复制  | 最通用，+faststart 优化网络播放         |
| MKV  | .mkv  | 流复制  | 开源容器，支持多轨                     |
| MOV  | .mov  | 流复制  | Apple 生态兼容                    |
| WEBM | .webm | 转码   | VP9 视频 + Opus 音频，可选 CRF/码率/线程 |

> 流复制模式（MP4/MKV/MOV）不重新编码，导出速度接近文件复制速度。WEBM 需要转码，耗时较长。
